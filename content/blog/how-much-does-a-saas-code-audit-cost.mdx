## 2. What Determines the Cost of an Audit?

A professional codebase audit is conducted by senior software architects line-by-line, not just an automated scan. The price is driven by:

### A. Codebase Size & Number of Repositories
A monolithic 20,000-line Next.js app requires fewer inspection hours than a distributed microservices system spanning 5 repositories and 150,000 lines of code.

### B. Database Schema Complexity
Profiling complex relational PostgreSQL schemas with dozens of tables, multi-tenant row-level security policies, and high-frequency transaction tables takes dedicated query plan analysis (EXPLAIN ANALYZE).

### C. Security & Access Control Review
Inspecting custom Role-Based Access Control (RBAC) matrices, JWT token lifecycles, and webhook signature verifications requires careful manual verification.

### D. Purpose of the Audit
A founder wanting an internal health check requires a practical developer roadmap, whereas an investor conducting pre-acquisition due diligence requires formal risk scoring and open-source license compliance audits.

## 3. What You Should Receive in Your Audit Report

A high-quality audit must provide actionable insights, not just 100 pages of automated linter noise:
1. **Executive Summary:** Plain-English strategic overview for non-technical founders and investors.
2. **Risk Classification Matrix:** Issues categorized by severity (Critical, High, Medium, Low).
3. **Database Performance Findings:** Exact SQL queries and suggested composite indexes.
4. **Prioritized Remediation Plan:** Step-by-step roadmap separating urgent week-1 hotfixes from longer-term refactoring.
5. **Architect Walkthrough Call:** A live 60-minute strategy call to answer questions.
